# Метод сопряженных градиентов
## Сборка и запуск

```bash
make          # собрать ./test_cg
make run      # собрать (если нужно) и запустить
```

## Команды Makefile

| Цель         | Действие                                                     |
|--------------|--------------------------------------------------------------|
| `make`       | Собрать исполняемый файл `test_cg`.                          |
| `make run`   | Собрать (если нужно) и запустить `./test_cg`.                |
| `make clean` | Удалить объектные файлы (`*.o`), модули (`*.mod`) и бинарник. |
| `make cleanall` | То же, что `clean`, плюс удаление `result.txt`.           |
| `make rebuild`  | Полная пересборка: `clean` + `all`.                      |

### Линейный поиск (strong Wolfe)

Реализован классический двухфазный алгоритм из
Nocedal & Wright, *Numerical Optimization*, гл. 3.

Требуются условия сильного Вольфа:

```
f(x + αp) ≤ f(x) + c1·α·(g·p)          — условие Армихо
|g(x + αp)·p| ≤ c2·|g·p|                — условие кривизны
```

Значения констант в модуле: `c1 = 1e-4`, `c2 = 0.9`.

Алгоритм состоит из двух подпрограмм:

1. **`line_search`** — фаза расширения шага (*bracketing*).
   Начинается с `α = 1`, при каждом успешном уменьшении `φ(α)`
   шаг удваивается. Как только нарушено условие Армихо или
   производная меняет знак, происходит переход в `zoom`.

2. **`zoom`** — бисекция внутри интервала `[α_lo, α_hi]`,
   в котором гарантированно лежит точка, удовлетворяющая
   условиям Вольфа. Итерации прекращаются, когда выполнились
   оба условия либо интервал сузился до `1e-12`.

### Численный градиент

Используется центральная разность:

```
∂f/∂x_i ≈ (f(x_i + h) − f(x_i − h)) / (2h)
h = ε_m^(1/3) · max(1, |x_i|)
```

где `ε_m ≈ 2.2e-16` для `dp = 8`. Такая величина шага
минимизирует суммарную погрешность аппроксимации и
округления, давая точность порядка `1e-10..1e-11`.

## Тестовые функции

| Функция       | Аналитическое выражение                                                 | Минимум                    |
|---------------|-------------------------------------------------------------------------|----------------------------|
| `quadratic`   | `(x₁−1)² + 2(x₂+3)² + 0.5(x₃−2)²`                                        | `(1, −3, 2)`, `f = 0`     |
| `rosenbrock`  | `(1−x₁)² + 100(x₂−x₁²)²`                                                 | `(1, 1)`, `f = 0`         |
| `himmelblau`  | `(x₁²+x₂−11)² + (x₁+x₂²−7)²`                                             | четыре точки, `f = 0`     |

Для каждой функции тестирующая программа запускает **оба варианта β** —
Fletcher–Reeves и Polak–Ribière+ — и выводит краткий вывод о том,
какой метод оказался эффективнее по числу итераций.

## Настройки по умолчанию

Для тестов используются следующие параметры:

| Тест              | `eps`    | `max_iter` | `restart_period` | `restart_gamma` | `ftol`   |
|-------------------|----------|------------|------------------|-----------------|----------|
| Квадратичная      | `1e-8`   | 2000       | 5                | 0.2             | `1e-14`  |
| Розенброк         | `1e-7`   | 50000      | 0 (выкл.)        | 0.1             | `1e-14`  |
| Химмельблау       | `1e-8`   | 2000       | 5                | 0.2             | `1e-14`  |

Для Розенброка периодический перезапуск отключён: на «овражной»
геометрии он только мешает (метод вырождается в градиентный спуск).
